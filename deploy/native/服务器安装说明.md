# crm.sogreat.cc 服务器安装包

适用目标：Alibaba Cloud Linux 4，root，已有Nginx官网。原官网sogreat.cc继续保留。此包不需要Docker，不包含密码、私钥、用户数据库或截图。

## 上传与安装

1. 独立安装包方式：将morocco-ai-crm-server.zip上传到服务器/root目录。
2. 在Workbench的Shell终端执行：

    crm_setup_dir=$(mktemp -d /root/crm-setup.XXXXXX)
    python3 -m zipfile -e /root/morocco-ai-crm-server.zip "$crm_setup_dir"
    python3 "$crm_setup_dir/morocco-ai-crm-server/install.py" --install

也可从本GitHub仓库的部署分支获取源码，解压后在项目根目录执行 `python3 deploy/native/install.py --install`。此方式不携带Node归档，安装器会从Node.js官方HTTPS地址取得固定版本并核对SHA256；不需要在服务器安装GitHub CLI或提供GitHub密钥（私有仓库则需由拥有访问权限的用户取得源码）。

安装会提示设置至少12位网页访问密码，输入不显示；密码不需要发到聊天里。包内带官方Node.js24.22.0 x64归档，并固定校验值；ARM64机器会从Node官网获取对应归档并验证固定SHA256。运行环境与应用放在/opt/morocco-ai-crm，不替换系统Node，也不安装Docker。

安装器先检查现有Nginx，寻找http层的独立*.conf包含目录；如果遇到已有非本安装器管理的CRM配置或客户数据库，会停止并保留。代码使用独立的moroccocrm系统用户运行，本机监听127.0.0.1:3010，数据库和截图位于/var/lib/morocco-ai-crm。密码只保存在服务器/etc/morocco-ai-crm/app.env（root可读）。Nginx只新增crm.sogreat.cc配置，并测试后reload；测试失败会恢复该新增配置之前的状态。初始HTTP仅开放证书校验路径，登录须等待HTTPS。

## DNS与HTTPS

在sogreat.cc的DNS管理中新增A记录，主机crm，值8.209.58.190，TTL默认；保留现有@、www及其他记录。确认没有冲突的crm/AAAA记录，等待解析生效后执行：

    python3 /opt/morocco-ai-crm/manage.py --https

此阶段复用系统Certbot，或在独立venv从PyPI安装官方Certbot；保留TLS与包校验。申请Let's Encrypt证书需接受该CA服务条款，安装命令会自动进行ACME注册（不提供邮箱）。证书仅用于crm.sogreat.cc，现有官网证书配置不变。申请成功后配置HTTPS代理及该证书的每日自动续期检查。真实证书签发需DNS和80/443公网可达；实际结果以运行输出为准。

## 状态、配置与备份

    python3 /opt/morocco-ai-crm/manage.py --status
    python3 /opt/morocco-ai-crm/manage.py --backup

备份命令会暂停本项目服务，以应用用户制作数据库和截图快照，然后恢复先前正在运行的本项目服务；备份位于/var/lib/morocco-ai-crm/backups/。不会停止Nginx或官网。请另行将备份保存到安全位置。

百炼密钥、实际地域接口和模型尚未配置。之后在服务器受保护的app.env中增加DASHSCOPE_API_KEY、DASHSCOPE_BASE_URL、QWEN_MODEL，重启morocco-ai-crm服务。不要把该文件内容发到聊天或加入源码包。固定示例可用于检验审核/记忆，真实翻译需另行验收。

本安装包初始部署不覆盖已有安装。安装完成后如需升级，请先备份并单独准备迁移，不能删除数据目录重装。

## 本次验证范围

- Node.js官方SHA256校验、归档解压及重复缓存校验通过；项目28项测试在24.22.0全部通过。
- 独立Nginx实例真实HTTP/HTTPS代理验证通过：测试官网保留、HTTPS前CRM登录关闭、受信测试证书校验、登录/Secure Cookie、固定草稿审核、运输需求、客户记忆、报价与导出。
- Nginx配置目录识别覆盖主配置http层、相对包含路径及常见面板目录；拒绝将server层include当作vhost目录。
- 尚未在用户服务器执行安装；实际systemd启动、SELinux策略适配、生产证书签发及公网登录需要继续现场验收。测试证书和测试私钥不包含在此安装包中。
